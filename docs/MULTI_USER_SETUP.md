# Independent installations

Stefan and Kevin will use the same product on separate computers, each with their own
guitars, interfaces and Kemper PROFILER Stage. One codebase/build; independent local
project files, Gear Vault, routing presets and calibration WAVs. No shared cloud gear
database, sync or GitHub login is implemented or required by the installed app.

Each OS user/machine stores data in its own Application Support/ToneReplicator folder.
Within an installation, interface presets use device UIDs and each guitar/pickup/mode
configuration has its own ID and capture history. A fresh installation starts with
blank gear fields. Optional model templates require the owner to confirm all details;
they are not user-specific ownership or manufacturer-verification claims.

Each person must select their own input/output channels and calibrate their actual
guitar through their own interface and the documented Kemper bypass output. Neither
Stefan's guitar calibration nor the SSL 2+ MKII live-test result transfers to Kevin's
gear. Software tests can be shared; physical routing and latency validation cannot.

Both computers are **Macs**, explicitly confirmed by the user. Current app supports
macOS 14+ only. Stefan uses a Mac mini; Kevin's Mac model/macOS and interface are not
yet supplied. Verify those prerequisites before claiming Kevin's installation ready.

User's intended new calibration path: Kemper Stage Monitor Output to the selected
interface's line input. Capture input/output processing, firmware, output source/level
and gain context separately for each owner's calibration. Existing direct-input
captures stay retained until explicit replacement, with prior path metadata preserved.
